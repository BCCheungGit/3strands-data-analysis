# 3Strands-Data-Analysis
Data analysis for [3Strands](https://threestrandssocial.online)

# Design and Implementation
- Converts user responses into vectors that can be transformed with linear algebra
- Uses cosine similarity algorithm to find the most similar user responses.
    - User responses are weighted manually in weights.json
    - Alternative algorithms considered: Euclidean distance, Jaccard similarity, Pearson correlation coefficient
